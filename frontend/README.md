# Frontend — Local Multi-PDF RAG Assistant

React 19 + Vite + TypeScript + Tailwind CSS + shadcn/ui interface for the Local Multi-PDF RAG Assistant.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173 (expects the backend at http://localhost:8000).

## Scripts

```bash
npm run dev       # dev server
npm run build     # type-check + production build
npm run lint      # eslint
npm run preview   # preview production build
```

See the [root README](../README.md) for the full project documentation.
